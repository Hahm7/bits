# Bits & Thoughts

Personal website of [Hamdi Ahmed](https://hamdiahmed.com): essays on companies and the economics behind how they behave.

**Live site:** [hamdiahmed.com](https://hamdiahmed.com)

## Stack

- [blogdown](https://pkgs.rstudio.com/blogdown/) and [Hugo](https://gohugo.io/)
- Theme: [Novela](https://github.com/forestryio/hugo-theme-novela)
- Hosted on [Netlify](https://www.netlify.com/), deployed from this repo
